# varika-fb

Visuels publiés sur la Page Facebook Varika. Ce dépôt est public pour que Facebook puisse récupérer les images par leur adresse.

Rien de confidentiel ici : uniquement des visuels destinés à être publiés.

- `AAAA-MM/` : visuels du mois, nommés `AAAA-MM-JJ-sujet.png` (date de publication prévue)
- `AAAA-MM/sources/` : code de génération (HTML/SVG selon la charte graphique, rendu avec Playwright)
